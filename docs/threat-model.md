# Threat model

Version 1 (M0) · STRIDE per component and data flow (spec 12.1) · Reviewed every release.

Risk IDs are stable and match `docs/risk/risk-register.md`. Status: **built** = control implemented and tested; **partial** = some layers built; **planned** = milestone named.

## Components and trust boundaries (M0)

```
[Browser] --HTTPS, __Host- session cookie--> [bff-patient] --service token (Ed25519, 60 s, aud=api)--> [api] --> [audit store]
                                                                                                        \--> (clinical DB: M1)
TB1: internet / BFF        TB2: BFF / API (mTLS planned)        TB3: API / data stores
```

## Known gaps in M0 (accepted for dev only)

- No mTLS between BFF and API yet.
- Dev sessions are in-memory and created at process start; no real authentication yet.
- Audit store is in-memory; deployed environments refuse to start.
- No rate limiting or CSRF tokens yet (no mutating routes exist).
